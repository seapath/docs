# Quick start

This beginner's guide will walk you through the step-by-step process of deploying your first SEAPATH infrastructure. It will cover all the essential tasks needed to get started with a default, commonly used architecture.

> [!NOTE]
> This quick start won't delve into technical specifics or customization options. For more advanced usage, please refer to the next sections.

This guide assumes that

- Your hardware is ready. Follow [Prerequisites](Prerequisites.md) for details about physical machine requirements.
- You have chosen between a Yocto-based and a Debian-based SEAPATH. Read [SEAPATH-Debian or SEAPATH-Yocto](SEAPATH-Debian%20or%20SEAPATH-Yocto.md) for more information.
- You have chosen between a standalone and a cluster setup. See [Standalone or cluster setup](Standalone%20or%20cluster%20setup.md) for more information.

- [Install SEAPATH](Quick%20start/Install%20SEAPATH.md)
- [Wire and connect to the machines](Quick%20start/Wire%20and%20connect%20to%20the%20machines.md)
- [Configure the machines](Quick%20start/Configure%20the%20machines.md)
- [Deploy your first virtual machine](Quick%20start/Deploy%20your%20first%20virtual%20machine.md)
