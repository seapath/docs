# Releases

SEAPATH releases follow semantic versioning: each release has a MAJOR.MINOR.PATCH format.

Major and minor releases are common to all SEAPATH components and all repositories are tagged together.  
Patch releases are specific to each component.

For example:

- For the 1.2.0 release, all repositories were tagged together as part of this release.
- The seapath-installer has a patch release 1.2.1 which is specific to this tool. It isn’t directly related to potential other 1.2.1 patch release from other SEAPATH repositories.  
  It is still compatible with other components in version 1.2.0, such as the SEAPATH Yocto and Debian 1.2.0 images.
