## Major API breaks

- Move to Ansible 2.16
- Move to cephadm to deploy Ceph
- Add compatibility with Debian 13 (Trixie) and drop Debian 12 (Bookworm) support
- Add compatibility with Yocto Wrynose and drop Yocto Scarthgap support
