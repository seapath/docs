# 1.1.0

Published February 25th, 2025

## Release notes

- Fix the build of a SEAPATH Yocto standalone image.
- Various fixes for SEAPATH Debian and Yocto.

This SEAPATH release uses two distributions :

- Yocto Scarthgap
- Debian 12 (bookworm)

This release is only compatible with x86 machines.

Technical release notes are accessible on the following repositories

- [ansible](https://github.com/seapath/ansible/releases/tag/v1.1.0)
- [build\_debian\_iso](https://github.com/seapath/build_debian_iso/releases/tag/v1.1.0)
- [yocto\_bsp](https://github.com/seapath/yocto-bsp/releases/tag/v1.1.0)
