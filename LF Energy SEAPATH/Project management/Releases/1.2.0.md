## Known issues

The seapath-installer crashes when used on a machine with a disk that has no partition. A work around exists, read more at <https://github.com/seapath/seapath-installer/issues/8>

## Report a bugs

If you encounter a bug when using SEAPATH v1.2.0, please report it on GitHub using the v1.2.0 label :

- [Ansible related bug](https://github.com/seapath/ansible/issues/new/choose)
- [Debian related bug](https://github.com/seapath/build_debian_iso/issues/new/choose)
- [Yocto related bug](https://github.com/seapath/yocto-bsp/issues/new/choose)
