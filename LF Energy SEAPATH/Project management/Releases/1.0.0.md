# 1.0.0

# Initial release

Published January 23rd, 2025

This release is the first official release of SEAPATH and thus contains every feature developed for the last 5 years on the project. The release changelog will then only highlight the key features of SEAPATH and will not list every change in the repositories.

## Release note

This SEAPATH release uses two distributions :

- Yocto Scarthgap
- Debian 12 (bookworm)

This release is only compatible with x86 machines.

Technical release notes are accessible on the following repositories

- [ansible](https://github.com/seapath/ansible/releases/tag/v1.0.0)
- [build\_debian\_iso](https://github.com/seapath/build_debian_iso/releases/tag/v1.0.0)
- [yocto\_bsp](https://github.com/seapath/yocto-bsp/releases/tag/v1.0.0)
