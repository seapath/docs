# Cluster redundancy

The redundancy ensure that the cluster resources (VM, containers , etc) are always accessible and operational on the cluster. Various clusters configurations are possible, among which:

- Active/active cluster: the resources are duplicated distributed along cluster nodes.
- Active/passive cluster: the resources are distributed on a single node, redounded by a recovery machine in case of a failure.

To get a better view of these configuration lets take a look applied to SEAPATH:

|  **Resource strategy**                                                                                                                                                                                                                                                                                                                                                                 |                                                                                                                                                                                                                                                                                                                 |
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Active/Active** (many instances)                                                                                                                                                                                                                                                                                                                                                     | **Active/Passive** (single instance)                                                                                                                                                                                                                                                                            |
| <ul><li><p><strong>Many VMs instances executed in the same time</strong></p></li><li><p>Higher hardware resources usage</p></li><li><p>Implementation example :</p><ul><li><p>Two VMs executed in parallel, without synchronization</p></li></ul></li><li><p>Lower service downtime</p><ul><li><p>Only resource downtime detection, no resource restart needed</p></li></ul></li></ul> | <ul><li><p><strong>A single VM instance executed in the same time</strong></p></li><li><p>Minimization of the needed hardware resources</p></li><li><p>Higher service downtime during a migration</p><ul><li><p>VM downtime detection</p></li><li><p>VM restart on another cluster node</p></li></ul></li></ul> |
