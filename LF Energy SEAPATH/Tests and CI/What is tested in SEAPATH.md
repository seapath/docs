# What is tested in SEAPATH

SEAPATH is designed to address critical applications for digital substations.

With 1000+ open-source tests, SEAPATH focus on what matters for digital substations:

- Resiliency
- Cybersecurity
- Real-time
- IEC 61850 latency tests

All tests are running on real-hardware for each pull request (new contributions) made on SEAPATH.

CIs are located for the moment at:

- RTE’s offices (Jonage, France)
- Savoir-faire Linux’s offices (Rennes, France)

More details on the CI are available on [Continuous integration on SEAPATH](Continuous%20integration%20on%20SEAPATH.md)
